## Before you begin

Most examples need:

- A JSONsilo account. [Sign up](https://console.jsonsilo.com/signup) to start a free trial.
- A silo. See [Create Silo](/how-to/create-silo).
- The right key for the job:

| Example | Key |
|---|---|
| Reading a public silo | None |
| Reading a private silo, Query, Search | [Access Key](/keys/access-keys) in `X-SILO-KEY` |
| Creating, updating, deleting silos | [Manage Key](/keys/manage-keys) in `X-MAN-API` |
| AI assistants | [MCP Key](/keys/mcp-keys) in `Authorization: Bearer` |

## Placeholders

The code uses these placeholders. Replace them with your own values.

| Placeholder | Where to find it |
|---|---|
| `[region-code]` | The silo's region, such as `api`, `sg-01-api`, or `usc-01-api`. See [Regions](/regions). |
| `[file-uuid]` | The **Silo UUID** on the silo's **Overview** tab. |
| `<YOUR_X_SILO_KEY_HERE>` | An Access Key you created under **Keys**. |
| `<YOUR_MANAGE_KEY_HERE>` | A Manage Key you created under **Keys**. |

<Tip>Rather than building a URL by hand, copy it from the **Silo URL** or **Public URL** card on the silo's **Overview** tab.</Tip>
