## What is JSONsilo.com?

JSONsilo is a simple tool for developers to host and share their `.json` files online without any hassle. You store a JSON document in a **silo**, and JSONsilo gives you a URL you can read it from with a single `GET` request.

### Key Features:
- **Easy Hosting**: Create a silo from pasted or uploaded JSON and get a URL instantly.
- **No Setup Required**: No need to configure servers or worry about hosting.
- **Public or Private**: Serve a silo to anyone with the URL, or require an Access Key.
- **3 Regions**: Host your silo in Germany, Singapore, or the United States.
- **Query & Search**: Read part of a private silo with query parameters instead of downloading all of it.
- **Schema Lock**: Attach a JSON Schema to a silo and reject any write that doesn't match it.
- **MCP Server**: Let AI tools such as Claude Code, Cursor, and VS Code read and edit your silos.
- **Manage API**: Create, update, and delete silos from your own code.
