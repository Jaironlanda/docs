## What is a Private Silo?

A Private Silo in JSONsilo is a secure storage solution for your JSON files that restricts access to authorized users only. Unlike public silos, which can be accessed by anyone with the link, private silos require an Access Key for access, ensuring that your data remains confidential and protected.

## Key Features of Private Silos

- **Access Control**: Only users with the correct Access Key can access the data stored in a private silo.
- **Query and Search**: You can perform advanced queries and searches on the JSON data stored in your private silo.

## Use Cases
- **Confidential Data Storage**: Store sensitive JSON data that should not be publicly accessible.
- **Internal Applications**: Use private silos to manage JSON data for internal applications that require restricted access.
- **Development and Testing**: Create private silos for development and testing purposes, ensuring that test data remains secure.

## URL Format

```bash
https://[region-code].jsonsilo.com/[file-uuid]
```

You can copy the full URL from the **Silo URL** card on the silo's **Overview** tab in the console.

## How to Create a Private Silo

To create a private silo, follow these steps:

1. Click **Silos** in the sidebar of the JSONsilo console.
2. Click on the `Create silo` button.
3. Enter a name and pick a region.
4. Leave the access switch on **Private**. This is the default.
5. Paste or upload your starting JSON.
6. Click `Create silo` to generate a unique URL.

For a full walkthrough, see [Create Silo](/how-to/create-silo).

To make an existing public silo private, open its **Settings** tab and choose **Private** under **Access**. The silo's URL changes when you do.

### Supported HTTP Method

A silo URL supports **GET** only. To create, update, or delete silos from your code, use the [Manage API](/api-reference/introduction).

### Errors

| Status | Meaning |
|---|---|
| `403` | The `X-SILO-KEY` header is missing. |
| `401` | The Access Key is invalid or was deleted. |
| `404` | The silo doesn't exist, or it belongs to another account. |
| `429` | You hit a [rate limit](/rate-limits). |

## Rate Limits

Private silos have the same rate limits as public silos depending on your [subscription plan](/pricing-plans). See [Rate Limits](/rate-limits).
