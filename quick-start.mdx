This guide takes you from a new account to your first request. The console walks you through the same three steps on its **Get started** screen.

## Before you begin

[Sign up here](https://console.jsonsilo.com/signup) if you don't have a JSONsilo account yet. After you sign up, we send a verification link to your email. Verify your email, then sign in.

<Note>New accounts start on a 2-day trial with every feature switched on. See [Pricing Plans](/pricing-plans#free-trial) for what the trial includes.</Note>

## Serve your first JSON in three steps

Open **Get started** at the top of the sidebar in the [console](https://console.jsonsilo.com). It tracks your progress and unlocks each step when the one before it is done.

{/* TODO: screenshot of the Get started screen. Suggested path: /images/quick-start/get-started.png */}

<Steps>
  <Step title="Create an API key">
    An Access Key authenticates requests to your private silos.

    Click `Create API key`, enter a key name, and click `Create key`. The **Key created** dialog shows the key once. Copy it, tick **I've stored this key somewhere safe**, and click `Done`.

    <Warning>Copy the key now. You won't be able to see it again.</Warning>

    You can create more keys later under **Keys**. See [Access Keys](/keys/access-keys).
  </Step>
  <Step title="Create your first silo">
    A silo is a JSON document you can read and write to via the API.

    Click `Create silo`, give it a name, pick a region, choose **Private** or **Public** access, and paste or upload your starting JSON. Then click `Create silo`.

    For a field-by-field walkthrough, see [Create Silo](/how-to/create-silo).
  </Step>
  <Step title="Make your first request">
    The last step shows a ready-to-paste `curl` command with your silo's real URL. For a private silo, replace the placeholder with your Access Key.

    Open the silo for JavaScript and Python examples.
  </Step>
</Steps>

## Silo URL format

Every silo gets a unique URL. The format depends on whether your silo is private or public:

<Note>Replace `[region-code]` with the appropriate region code for your silo, and `[file-uuid]` with the unique identifier assigned to your JSON file.</Note>

#### Private Silo URL Format
```bash
https://[region-code].jsonsilo.com/[file-uuid]
```

#### Public Silo URL Format
```bash
https://[region-code].jsonsilo.com/public/[file-uuid]
```

### Supported Region Codes

| Region Code   | Description            |
|---------------|------------------------|
| `api`         | Germany (default)      |
| `sg-01-api`   | Singapore region       |
| `usc-01-api`  | US Central region      |

For more details about supported regions, please refer to the [Regions Documentation](/regions).

#### Retrieving your file uuid and region code

You don't have to build the URL by hand. Sign in to the console, open **Silos**, and click one of your silos.

On the **Overview** tab:

- The **Silo URL** card (or **Public URL** for a public silo) shows the full URL with a copy button.
- The **Details** card shows the **Silo UUID** and the **Region**. Click the UUID to copy it.

{/* TODO: screenshot of the silo Overview tab with the URL and Details cards. Suggested path: /images/quick-start/silo-overview.png */}

You can also copy either value from the silo list: open the actions menu at the end of a row and choose `Copy URL` or `Copy UUID`.

### Retrieving your Access Key for Private Silo

To create an Access Key for a private silo, open **Keys** in the sidebar and select **Access keys**. Click `New access key`, enter a key name, and click `Create key`.

After creating the Access Key, make sure to copy and save it securely, as you will need it to access your private silo.

<Warning>If you lose your Access Key, you can create a new one by following the same steps. Make sure to delete any old keys that you no longer use to keep your account secure.</Warning>

### Accessing Your JSON File

Below are examples of how to access your JSON file using the generated URL.

<Tabs>
  <Tab title="cURL" icon="terminal">
    **Accessing a Private Silo**

    To access a private silo, include your Access Key in the request headers. Use the `X-SILO-KEY` header to provide your Access Key.
    
    ```bash Terminal
    curl -X GET \
      -H 'X-SILO-KEY: <YOUR_X_SILO_KEY_HERE>' \
      -H 'Content-Type: application/json' \
      https://[region-code].jsonsilo.com/[file-uuid]
    ```

    **Accessing a Public Silo**
    
    For public silos, you can access the JSON file directly without any authentication headers.
    
    ```bash Terminal
    curl -X GET \
      -H 'Content-Type: application/json' \
      https://[region-code].jsonsilo.com/public/[file-uuid]
    ```
  </Tab>
  
  
  <Tab title="JavaScript" icon="code">

    **Accessing a Private Silo**

    To access a private silo, include your Access Key in the request headers. Use the `X-SILO-KEY` header to provide your Access Key.

    ```javascript main.js
    fetch('https://[region-code].jsonsilo.com/[file-uuid]', {
      method: 'GET',
      headers: {
        'X-SILO-KEY': '<YOUR_X_SILO_KEY_HERE>',
        'Content-Type': 'application/json'
      }
    })
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error('Error:', error));
    ```

    **Accessing a Public Silo**

    For public silos, you can access the JSON file directly without any authentication headers.

    ```javascript main.js
    fetch('https://[region-code].jsonsilo.com/public/[file-uuid]', {
      method: 'GET',
      headers: {
        'Content-Type': 'application/json'
      }
    })
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error('Error:', error));
    ```
  </Tab>
  <Tab title="Python" icon="code">
    **Accessing a Private Silo**

    To access a private silo, include your Access Key in the request headers. Use the `X-SILO-KEY` header to provide your Access Key.

    ```python main.py
    import requests

    url = 'https://[region-code].jsonsilo.com/[file-uuid]'
    headers = {
        'X-SILO-KEY': '<YOUR_X_SILO_KEY_HERE>',
        'Content-Type': 'application/json'
    }

    response = requests.get(url, headers=headers)
    if response.status_code == 200:
        print(response.json())
    else:
        print('Error:', response.status_code)
    ```

    **Accessing a Public Silo**

    For public silos, you can access the JSON file directly without any authentication headers.

    ```python main.py
    import requests

    url = 'https://[region-code].jsonsilo.com/public/[file-uuid]'
    headers = {
        'Content-Type': 'application/json'
    }

    response = requests.get(url, headers=headers)
    if response.status_code == 200:
        print(response.json())
    else:
        print('Error:', response.status_code)
    ```
  </Tab>
</Tabs>
