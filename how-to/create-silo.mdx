## Introduction

Creating a silo in JSONsilo allows you to securely store and manage your JSON files. This guide will walk you through the steps to create a new silo, and access it using the unique URL provided.

<Steps>
  <Step title="Navigate to Silos">
    Click **Silos** in the sidebar.

    You will see a list of existing silos if you have any. Click the `Create silo` button at the top right. If you have no silos yet, the button is in the middle of the empty screen.

    {/* TODO: screenshot of the Silos screen with the Create silo button. Suggested path: /images/create-silo/silos-list.png */}
  </Step>
  <Step title="Name your silo">
    In the **Create a new silo** dialog, enter a **Name**.

    The name is for your reference only. It won't appear in the JSON served from your silo's URL. If you leave it empty, the silo is listed as **Untitled silo**.
  </Step>
  <Step title="Pick a region">
    Choose **Germany**, **Singapore**, or **United States**. Pick the region closest to the apps that will read the silo to minimize latency.

    The region is part of the silo's URL. See [Regions](/regions).
  </Step>
  <Step title="Choose the access type">
    Use the switch to choose how the silo can be read.

    <Tabs>
      <Tab title="Private Silo" icon="lock">
        Requires a valid [Access Key](/keys/access-keys) to read, and keeps your JSON protected from unwanted access. This is the default.
      </Tab>
      <Tab title="Public Silo" icon="globe">
        No Access Key required. Anyone with the URL can read your JSON.
      </Tab>
    </Tabs>
  </Step>
  <Step title="Add your starting JSON">
    Under **Starting JSON**, either type or paste your JSON into the box, or click `Upload .json` to load a file from your computer. An uploaded file is checked and formatted for you.

    The box starts with an empty object, `{}`. You can keep it and add your data later in the editor.

    {/* TODO: screenshot of the Create a new silo dialog. Suggested path: /images/create-silo/create-dialog.png */}
  </Step>
  <Step title="Create the silo">
    Click `Create silo`.

    The console opens your new silo on the **Data & schema** tab, where you can keep editing the JSON. See [Data & Schema Editor](/editor/json-editor).
  </Step>
</Steps>

That's it! You have successfully created a silo in JSONsilo. ✨

<Note>Each plan has a limit on how many silos you can create and how large each one can be. See [Pricing Plans](/pricing-plans).</Note>

## Other ways to create a silo

- **Manage API**: Send a [Create Silo](/api-reference/endpoint/create-silo) request with a Manage Key.
- **MCP**: Ask a connected AI tool to create one. See [MCP Tools](/mcp/tools).
